## 三、商业模式（核心情报）

1. **免费建校 → 私域变现**：学生自己建校运营，"如何免费创建新学校"引导加企业微信（即链负责人）
2. **资料钩子引流**：川财页放"开学考试资料 197.6MB PDF / 班委竞选步骤 / 班级课表"——**"私信领入学考试资料"**（加好友领资料 → 私域沉淀）
3. **密码解锁**：部分内容（如武纺）要"密码解锁"，密码私信公众号后台获取 → 关注/加微信引流
4. **寻伴群**：校内寻伴引导扫码进微信群 → 社群运营
5. 学校规模数据：school-search 返回 uv（盐城工学院 5423、安徽交通 2669、河北政法 2663…川财 1149）——单字母枚举可拉 125+ 校

## 五、我们的差异化对策（已落地）
