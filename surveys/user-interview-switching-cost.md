# 学生视角：什么能让我从 QQ/微信彻底切换到 CampusLink

> **来源**：深度用户访谈 — 一位在校学生的真实想法  
> **核心问题**：切换成本是最大的壁垒，CampusLink 必须提供 QQ/微信给不了的东西  
> **日期**：2025-06

---

## 🏆 能让学生彻底切换的 Killer Features

### 1. 教务一键打通（课表 + 成绩 + 考试安排）

这是最刚的刚需。如果 CampusLink 能做到：
- **一键从教务系统同步课表**（而不是拍照片 OCR 或手动添加）
- **课表变动自动推送**（调课/停课/换教室不用等学委在群里吼）
- **成绩出分即时通知**（不用每隔 10 分钟刷一次教务系统）
- **考试时间自动同步到课表**

> 超级课程表能做课表但做不了成绩推送，今日校园能做通知但课表不好用——**谁能把这两件事在一个地方做通，我就用谁**。

### 2. 内置即时通讯（私信 + 群聊）

当前 CampusLink 最大的断层：看到二手好物 → 想联系卖家 → **"加个微信聊"** → 跳走了，再也没回来。

如果 CampusLink 有：
- **内置私信**，看完直接聊，不需要加微信
- **班级/年级官方群**，能替代 QQ 群（通知已读、文件共享、群公告自动归档）
- **二手交易沟通模板**（"还在吗？""多少钱？""什么时候面交？"一键发送）

> 可以在 CampusLink 里完成**从看到买到聊**的闭环，不需要切出去。这是留存的关键。

### 3. 失物招领 + 智能匹配

现在的失物招领是：丢东西 → 发 CampusLink → 等别人刷到。效率太低。

如果：
- **捡到东西拍照上传，系统自动和最近的失物帖子匹配**
- **匹配成功 → 双方同时收到通知**
- **各院系有专门的失物点 + 二维码，扫一扫直接关联 CampusLink 帖子**

> 比在几百条 QQ 群消息里发"有没有人看到我的校园卡"靠谱一万倍。

### 4. 二手交易闭环（校内信用体系 + 担保交易）

- 闲鱼的问题：非校内人员混杂，面交不安全
- QQ 二手群的问题：信息混乱，没有评价，全凭良心

如果 CampusLink 有：
- **校内信誉分**（成功交易 +1，放鸽子/纠纷扣分，实名可追溯）
- **担保交易/校内代管**（小额资金平台托管，确认收货后放款）
- **一键生成"面交码"**：买家扫码确认，交易完成自动互评

> 闲鱼的信誉体系对校内交易来说太粗糙了，CampusLink 可以做得更精细。

### 5. 通知聚合 + 不再错过任何事（Push）

现状：班级群、年级群、院系群、学生会群、课程群……每天几百条消息，真的通知反而被刷掉。

如果 CampusLink 能做到一个**干净的校园通知中心**：
- ✅ 学校官方通知（停水停电、考试安排）
- ✅ 课表变动提醒
- ✅ 我收藏的帖子有人回复
- ✅ 我发的二手有人问
- ✅ 活动报名即将开始
- ❌ 没有闲聊、没有刷屏、没有表情包接龙

> 这个"纯净度"是 QQ/微信群永远做不到的——因为群聊的本质就是刷屏。

### 6. 校园圈升级（比校园墙好用的匿名 + 兴趣圈子）

现在的校园墙（QQ 墙）模式是：发消息给墙 → 墙发出来 → 评论区乌烟瘴气。

如果 CampusLink 能做到：
- **实名 + 匿名一键切换**发帖（不用换小号）
- **分圈子关注机制**：只关注"二手交易"和"学习互助"，不刷到不想看的内容
- **帖子热度排序 + 精华区**（而不是时间线刷屏）
- **兴趣同好匹配**：勾选"摄影"→有摄影活动/帖子优先推给我

> 比校园墙和百度贴吧都好用——因为它是**为校内学生量身定制**的。

## 📊 功能优先级排序

| 功能 | 切换驱动力 | 理由 |
|------|:---------:|------|
| 教务一键同步（课表+成绩+考试） | ⭐⭐⭐⭐⭐ | 每日刚需，超级课程表能做到 60%，CampusLink 能做到 100% 我就走 |
| 内置私信 + 群聊 | ⭐⭐⭐⭐⭐ | 从"加个微信"变成"直接聊"，减少跳出 |
| 校内信誉分 + 担保交易 | ⭐⭐⭐⭐ | 闲鱼做不到的点，校园场景专属壁垒 |
| 通知聚合（纯净版） | ⭐⭐⭐⭐ | 解决了"被微信群刷屏淹死"的痛点 |
| 失物智能匹配 | ⭐⭐⭐ | 场景频率不高，但一旦用上就离不开 |
| 校园圈 + 匿名双模式 | ⭐⭐⭐ | 比校园墙好用但不是决定性因素 |
| 空教室查询 / 自习室座位 | ⭐⭐⭐ | 高频但非刚需替代品（超课表也有） |

## 🔗 与现有产品策略的关联

本访谈为 `campus-exclusive-layer.md`（校园专属层产品策略白皮书）提供了**来自真实用户的一手验证**：

| 白皮书论点 | 学生访谈验证 |
|-----------|-------------|
| 信息结构扁平化 → 需要结构化信息 | ✅ 通知聚合、分类圈子、搜索存档 |
| 社交关系泛化 → 需要角色隔离 | ✅ 实名+匿名一键切换、兴趣圈子关注机制 |
| 校园场景缺失 → 需要原生适配 | ✅ 教务打通、担保交易、失物匹配全是专属场景 |
| 迁移锚点 P0：教务+消息 | ✅ 教务同步和内置私信并列最高分 ⭐⭐⭐⭐⭐ |
| 校园专属层 5 层架构 | ✅ 从信息层到信任层的每个层次都有用户需求印证 |

---

## 📝 关键洞察

**一句话总结**：CampusLink 不需要做成"另一个 QQ"，而是要做成 **QQ/微信做不到的校园专属层**——把课表、成绩、通知、交易、社交串在一起，让校园生活的每一个动作都能在一个地方完成。当学生发现「用 CampusLink 一天可以少切 5 个 App、少爬 10 个群消息」的时候，切换就是自然而然的。
