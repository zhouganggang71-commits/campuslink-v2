# CampusLink 校园平台 — 调研问卷与用户研究

本目录包含两份调查问卷及一份用户深度访谈，旨在全面了解 CampusLink（校园连）用户的使用体验以及学生在其他校园/社交平台上的行为偏好。

| 文件 | 类型 | 目的 |
|------|------|------|
| `survey-campuslink-usage.md` | 调查问卷 | 收集 CampusLink 注册用户的功能体验、满意度、痛点、改进建议 |
| `survey-other-platforms.md` | 调查问卷 | 了解全体在校学生使用其他校园/社交平台的场景、偏好、习惯 |
| `user-interview-switching-cost.md` | 用户访谈 | 在校学生对"切换成本"的真实看法：什么 Killer Features 能让他们从 QQ/微信迁移过来 |
| `campus-exclusive-layer.md` | 产品策略 | QQ/微信做不到的校园专属层 — 产品策略白皮书 |

> **💡 最新添加**：`user-interview-switching-cost.md` 是一份来自真实学生的深度反馈，为 `campus-exclusive-layer.md` 的产品策略提供了用户侧的一手验证。强烈建议产品团队在制定 Roadmap 时将其作为优先参考。两份问卷均可导出为在线表单（如问卷星、腾讯问卷、金数据）进行投放。建议通过班级群、校园圈、公众号等渠道推送给四川财经职业学院全体学生。

投放建议：
- **样本量目标**：每份问卷 ≥ 200 份有效答卷
- **奖励机制**：提交后抽奖（奶茶券/校园周边），提高参与率
- **投放时间**：学期中（避开考试周），投放 7-10 天
